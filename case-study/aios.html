Case study 01 · Claude Code

AIOS: an AI operating system for a one-person business

Context
Internal build, used daily
Stack
Claude Code · slash commands · session memory
Pillars
Build → Teach

The challenge

A founder-led studio has one operator wearing every hat: client delivery, lead generation, content creation, sales pipeline, admin. Each hat has its own tools, its own context, and its own switching cost — and the switching cost is where the day disappears.

The question behind AIOS: could one AI environment hold all of it — not as a chatbot you ask things, but as an operating system that runs the business's routines?

The approach

AIOS was built inside Claude Code as a set of eleven slash commands, each one owning a business function:

  • Daily briefing — one command compiles inbox, pipeline and job status into a single morning read.
  • Client delivery — engagement workflows with their context, files and next steps loaded on demand.
  • Lead generation and pipeline — prospect research, scoring and follow-up tracking.
  • Content creation — drafting workflows tuned to a specific voice across four platforms.
  • Session memory — what happened last session carries into the next, so context is never rebuilt by hand.

The design rule throughout: a command earns its place by being used daily — anything that demoed well but wasn't reached for got cut.

Outcomes

Why this matters

AIOS is the studio eating its own cooking. The same pattern — map the routines, wire them into an AI environment, cut what isn't used — is what a client engagement looks like, applied to your business instead of ours.

It's also proof that the interesting frontier isn't "using AI tools." It's giving a business one place where its context lives and its routines run.
